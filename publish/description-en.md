Build your own tabletop games inside Minecraft.

An in-game editor lets you design **cards, pieces, boards and rules** — rules are written in a built-in scripting language, so no Java needed. The **Game Table** block turns a game definition into a real match for you and your friends: multiple players around one table, automatic dealing, rules driven by your script. Whole games are **importable and exportable**.

What's in it:
- **Card Table & chairs** — card tables connect automatically (connected textures, corner pieces); chairs are sittable
- **In-game design editor** — scripts (visual node graph + text views), stage/UI canvas, cards, pieces, asset library, values, world areas, vanilla data (loot tables / recipes / villager trades / tags)
- **Game Table** — runs a full match from your game definition (start / deal / score / end all live in the script)
- **Multiplayer drawing board** — real-time collaborative pixel art with named projects and JSON import/export

Requires Minecraft **26.1.2** · NeoForge · must be installed on **both client and server**.
