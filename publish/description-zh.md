在 Minecraft 里搭建属于你自己的桌游。

游戏内编辑器让你设计**卡牌、棋子、棋盘与玩法规则**（自带一套脚本语言，写规则不用写 Java）；**游戏台**把整套游戏定义驱动成真实的桌上对局 —— 多人同桌、自动发牌、按规则推进。整套玩法可**导入导出**，也能从别处搬进来。

现在能做什么：
- **棋牌桌 / 椅子**：相邻自动拼桌（连接纹理 + 转角件），椅子可坐（座位实体、四朝向碰撞）
- **游戏内设计编辑器**：脚本（可视化节点图 + 文本双视图）、界面画布、卡牌、棋子、组件库、数值、世界区域、原版数据（战利品表 / 配方 / 村民交易 / 标签）
- **游戏台**：读游戏定义驱动一整局 —— 开局 / 发牌 / 计分 / 结束都写在脚本里
- **多人画板**：实时协作像素画板，命名项目存档、JSON 导入导出

支持 Minecraft **26.1.2** · NeoForge · 客户端与服务端**都要安装**。
